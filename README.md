# KEIRIN FLOW

競輪のレース展開を、選手ごとの AI が自分で判断して走るデジタルツインです。

公開サイト: https://shigemarukun.github.io/keirin-flow/

考え方と判断基準は [プロジェクト憲章](docs/KEIRIN_FLOW_PROJECT_CHARTER.md) にまとめています。

## できること

1. **出走表を入れる** — 出走表のページの文字をコピーして **貼り付けるだけで読み取り** (選手・級班・得点・脚質・B/S・決まり手・並び・競輪場)。手で直すこともできる。6車・7車・単騎あり、**ガールズ**(ラインなし・ブロックなし)、**級班**(SS〜A3)と **経歴**(元SS・特別昇級など) に対応
2. **AIの展開予想を見る** — 選手の調子を少しずつ変えて30回走らせ、一番よく起きた展開を **本線**、次を **対抗**・**穴** として、展開の文章・決まり手・着順・印(◎○▲△)・1着率/3着内率を表示。**AIの選手の見立て** で、誰がなぜ強いのか(得点→級班・経歴で補正→地力)、ラインでの役割と戦法、千切れやすさが分かる
3. **展開を変える** — ラインの前後をタップで入れ替え、ラインごとに 先行 / カマシ / 捲り / 追込、前受けに **突っ張る / 引く(後方まで下げて巻き返す) / 中団(前に入れたラインの後ろを取る)** を指定
   - **WINTICKETのEXデータ** (戦法別・ライン先頭時・番手時・バンク別・レース種別) を貼り付けると、前受けの動きの割合 (突っ張りの回数÷前受けの機会)、千切れやすさ (ちぎられ率)、ダッシュ力 (ちぎり率)、得意な位置・バンク・レース種別を反映。回数の少ない100%は過大評価しない。「—」はデータなしとして扱う
   - 並びが無ければ、AIが地区と先行度から並びを予想して入れる (自由に直せる)
   - 本線・対抗・穴は「どのラインが主導権を取るか」の展開ごとに分ける
4. **展開ごとの買い目 (3連単)** — 選んだ展開 (AIの本線でも、自分で編集した展開でも) になった回から、本命 / 抑え / 穴 と点数 (固ければ少なく、荒れそうなら最大24点)、「カマしに出やすい」「千切れやすい」などの起きそうなことを表示。「2-4-9,5」のようにまとめた書き方でコピーできる。印 (◎○▲) は本線に合わせる。オッズはまだ使っていない
5. **コースで見る** — 本線・対抗・穴の展開を、その回の調子のまま再生。実況テロップと「ここから見る」(赤板・打鐘・最終周・バック・直線)
6. **答え合わせ** — 実際の着順を入れると、AIの本線と比べて当たり外れ・AIがその結果を何%と見ていたかを表示。記録は端末に残る
7. **予想をリンクで送る** — 出走表と展開の指定をURLにして、LINEなどで送れる

## いまの仕組み (v0.17 自律AIモード)

各選手は毎フレーム、自分の状況を見て判断します。台本や車番の決め打ちはありません。

| 段階 | 中身 |
|---|---|
| SENSE | 残り距離、自分の残脚、前後・外側の選手、ラインの仲間 |
| ASSESS | 能力から決まる脚質 (先行 / 捲り)、仕掛け地点、相手の脅威 |
| DECIDE | 突っ張る・出させる・先行・捲り・番手牽制・自力切替・追い込み など |
| ACT | 目標速度と走路をエンジンに渡す |
| REASSESS | 選手ごとの記憶。状況が変われば判断も変わる |

判断を変えたときは、Decision Log に理由と数字 (残脚など) が出ます。

### 能力値の効き方

`race-plan.js` の `DEFAULT_RACE_SETUP` で選手の能力 (0〜1) とラインを設定します。

- `power` … 維持できる最高速
- `acceleration` … スプリントの上乗せ
- `endurance` … 脚の減りにくさ
- `tacticalIQ`, `aggression` … 仕掛ける位置とタイミング
- `blockSkill` … 番手の牽制の強さ
- `mindset` … 前受け時の対応 (`TSUPPARI` 突っ張り / `YIELD_AND_ROLL` 出させる / `CONTAIN`)

## 再現できる競輪の動き

誘導切り / 突っ張り / 出させる(引く) / 先行 / 叩き / カマシ / 捲り / 番手ブロック / 番手捲り / 切り替え / 並走の踏み合い / 逃げのタレ / 内すくい / 包まれて出られない / 単騎の自力・追走

`npm test` で、いろいろな並び・能力のレースの中でこれらが実際に起きることを毎回確かめています。

## 展開を選ぶ

画面の「展開を選ぶ」で、ラインの先頭(と単騎)ごとに **先行 / カマシ / 捲り / 追込** を、前受けの先頭には **突っ張る / 出させる** をタップで指定できます。「おまかせ」はAIが能力から決めた戦法です。指定は出走表と一緒に保存されます。

## 出走表の入力 (v0)

画面の「出走表を入力」に、車番ごとの 選手名・競走得点・脚質(逃/両/追)・B回数・S回数 と、並び(例 `123/456/789`)を入れて「この出走表で予想する」を押すと、そのレースが走ります。入力は端末に保存され、次に開いたときもそのまま残ります。

どの入口(手入力・スクショ・URL)から来ても、最後は `race-data.js` の「レースデータ」形式にそろえてから能力値に変換します。

| 出走表の項目 | 使い道 (変換ルール v0・仮の数字) |
|---|---|
| 競走得点 | 地力 `power`。レースのクラスの「ふつう」の得点(S級100 / A級86 / チャレンジ72 / ガールズ50)との差で決める (1点=0.0125、ガールズは2.5倍) |
| 級班 (SS〜A3・L1) | 得点は直近4か月、級班は半年の成績。級班の「ふつう」の得点を2割まぜて、調子の波をならす (同じ得点なら上の班が強い) |
| 経歴 | 昇級したばかり=得点を−4 (下のクラスで取った得点) / 特別昇級=−1 (下のクラスの得点−4、勢い+3) / 元SS・元S1・元S2・元A1=本来の格の得点−4を下限にする |
| 脚質 | 逃=先行寄り / 両=捲り寄り / 追=番手・マーク寄り |
| B回数 | 先行意欲 `aggression` |
| S回数 | 「隊列をAIに任せる」ときの前受けの決め方 |
| 決まり手(逃・捲・差・マ) | 実際にどう勝ってきたか。逃げが多い=先行寄り・長く踏める、捲りが多い=捲り寄り・ダッシュ力、差し・マークが多い=直線の伸び。8回以上で目いっぱい反映 (脚質より優先) |
| 並び | ライン構成と周回の並び順 (一番大事な入力) |
| ギヤ倍数・年齢・級班 | v0 では未使用 (効くか後で検証) |

## 主なファイル

| ファイル | 役割 |
|---|---|
| `race-ai.js` | 選手の判断 (自律AI本体) |
| `engine.js` | 物理: 速度・脚の消耗・風よけ・走路の重なり防止 |
| `race-plan.js` | 能力値・ライン構成の設定 |
| `race-data.js` | 出走表(レースデータ)の形式と、能力値への変換ルール |
| `race-input.js` | 出走表の手入力画面 |
| `tactics-panel.js` | 展開をタップで選ぶ画面 |
| `tenkai-predictor.js` | スタート前の展開予想 (誘導切り・前受け・捲り候補) |
| `race-story.js` | 走ったレースから展開の文章と決まり手を組み立てる |
| `forecast.js` / `forecast-worker.js` | 調子を変えて何十回も走らせ、本線・対抗・穴と確率を出す (画面を止めないよう別スレッドで計算) |
| `forecast-panel.js` | 「AIの展開予想」の画面 |
| `results-panel.js` | 答え合わせ |
| `track.js` | バンクの形 (333/400/500)、コーナーで外を回ると遠回りになる計算 |
| `ui.js` / `main.js` | 画面表示 |
| `scenario-phase-manager.js` | 旧・教材シナリオ (台本)。`mode: 'TEACHER'` のときだけ使用 |

## テスト

```bash
npm test          # 自律AIのテスト (実データに近いか も含む) + 出走表の変換テスト
npm run test:teacher   # 旧・教材シナリオのテスト
```

`npm test` は「決まった着順になるか」ではなく、「AI が本当に自分で判断しているか」を確かめます。

## スマホで使う

1. iPhone の Safari で公開サイトを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから、アプリのように全画面で開ける (一度開けば電波がなくても動く)

LINE などでURLを送ると、タイトルと画像付きのカードで表示されます (`og-image.png`)。

## 動かし方

`index.html` を静的 Web サーバーで開きます (GitHub Pages ではそのまま動きます)。
