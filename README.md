# KEIRIN FLOW — CR-0010 PHASE-DRIVEN TSUPPARI_MAKURI

CR-0009までの「各Riderが展開そのものを自由判断する」本番経路を停止し、
展開予想で選ばれた競輪シナリオを `ScenarioPhaseManager` が進行し、
PhysicsEngineは速度・レーンを滑らかに補間する構造へ変更したリリースです。

## 教師シナリオ

`TSUPPARI_MAKURI`

1. 7-8-9 誘導切り
2. 1-2-3 突っ張り / 789後退 / 3ライン再整列
3. 789再仕掛け / 123と外並走 / 456中団待機
4. 789失速 / 456大外捲り / 1失速
5. 4-5ワンツー / 2-6三着争い / 1・789後退

## 物理上の保証

- フェーズ境界でも速度は加速度・減速度上限を通して補間
- レーン変更は laneRate による連続補間
- Phase 4は 4 → 5 → 6 の順で外へ持ち出し、ラインの「しなり」を表現
- Phase 3以外はライン追走・ライン単位のドッキングを優先
- 玉突き式の速度インパルスは使用しない
- 同一走行帯の安全車間をサブステップ単位で保護
- 乱数なし・同じ設定では同じ教師展開
