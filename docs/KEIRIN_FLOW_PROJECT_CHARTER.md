# KEIRIN FLOW プロジェクト憲章

この文書は、実装の細かいことではなく「何を作るのか」「何を大事にするのか」「迷ったときにどう決めるのか」を書いたものです。
機能を足すとき、直すときは、まずここに照らして判断します。

---

## 1. 何を作るのか

**競輪の展開予想ツール**であり、**競輪のデジタルツイン**です。

- 出走表を入れると、AIが **スタートの隊列 → 展開の文章 → 着順までの動き** を出す
- それを見た人が、並びを入れ替えたり、展開(突っ張る / 出させる / 先行 / カマシ / 捲り / 追込)を切り替えたりして、**自分の予想として走らせられる**
- 「もしこの選手が突っ張ったら?」「もし出させたら?」を試して、**競輪の戦術の仕組みが分かる**

予想の数字を表示するだけのアプリではありません。「なぜその着順になるのか」が見えることが一番の価値です。

### 目標
- 毎レース前に、自分(しげちゃん)が開きたくなる道具にする
- URLを知っている人なら誰でも、スマホで、無料で、一人で使える

---

## 2. 原則

### 2-1. 台本を書かない
- 選手の動きは、能力・残脚・位置・ラインでの役割から、その場で判断する
- **車番やラインの名前で動きを決め打ちしない** (テストで毎回確かめる)
- 「この展開にしたい」ときは、台本ではなく、ユーザーが選べる **展開の指定** として入れる

### 2-2. 説明できること
- 選手が判断を変えたら、Decision Log に **理由と数字** (残脚・相手との差など) を出す
- 展開の文章は、実際に走らせたレースから組み立てる (作文しない)
- 予想には **不確かさ** を必ず添える (何通りもの未来、1着率・3着内率、本線 / 対抗 / 穴)

### 2-3. 同じ条件なら同じ結果
- 乱数を使うときも種(seed)から作る。同じ出走表・同じ指定なら、何度開いても同じ予想になる
- 再生速度(0.5〜3倍)で結果が変わらない

### 2-4. 実際の競輪に合わせる
- 見た目がそれっぽいだけの動きより、**実際の競輪の戦術** を優先する
- 「それっぽい」ではなく、**実データと比べて** 調整する (下の 4. を参照)
- 合わないところは隠さず書く

### 2-5. スマホで、一人で、無料で
- 計算は見ている人のスマホの中で行う。サーバーも有料のAIも使わない
- iPhone の画面幅で、指で操作できることを前提にする
- お金がかかる仕組み(AIの自動読み取りなど)を公開サイトに入れるときは、誰が払うのかを先に決める

---

## 3. 判断基準 (迷ったとき)

| 迷うこと | どう決めるか |
|---|---|
| 新しい動きを足すか | 実際の競輪で起きる動きか? 起きるなら、決め打ちではなく「条件がそろったら起きる」形で足す |
| 数字を調整するか | 実データ(4.)に近づくか? 近づくなら採用。テストの数字も実データ基準にする |
| 見た目と中身が食い違う | 中身(シミュレーション)を正とし、見た目を合わせる |
| 予想と確率が食い違う | 何通りもの未来で一番多かった展開を「本線」にする |
| 機能を増やすか | しげちゃんが毎レース前に使うか? 使わないなら後回し |
| 友達向けの機能 | まず自分が「使える」と判断してから |

## 4. 実データの目標値 (調整の基準)

調べた範囲の数字です。出典の集計方法はそれぞれ違うので「目安」として使います。

### 1着の決まり手 (バンク別)
| バンク | 逃げ | 捲り | 差し |
|---|---|---|---|
| 333 | 33% | 31% | 36% |
| 400 | 25% | 30% | 45% |
| 500 | 24% | 26% | 50% |

出典: [競輪の決まり手の意味は？見方やバンクごとの割合など](https://www.centresource.com/column/keirin-kimarite/)

### ライン位置別の成績 (男子7車・ライン付き23万人超)
| 位置 | 1着率 | 3着以内率 |
|---|---|---|
| 先頭 | 21.6% | 49.2% |
| 番手 | 14.9% | 46.9% |
| 3番手 | 2.6% | 32.5% |
| 単騎 | 6.8% | 25.7% |

出典: [番手は本当に"おいしい"のか｜競輪のラインを実データで検証](https://yutakacraft.jp/keirincraft/lab/bante)、
[番手はなぜ強いのか——ライン位置別の3着内率](https://rindokulab.hatenablog.com/entry/2026/09/06/091213)
(格上番手は格下番手より3着内率が約8ポイント高い)

### 現在のシミュレーション (いろいろな並び・得点で72レース)
| | 結果 | 目標 |
|---|---|---|
| 400の決まり手 | 逃げ24% / 捲り21% / 差し56% | 25 / 30 / 45 |
| 333の決まり手 | 逃げ32% / 差し51% | 33 / 36 |
| 500の決まり手 | 逃げ18% / 差し68% | 24 / 50 |
| 先頭の1着率 | 17.3% | 21.6% |
| 番手の1着率 | 16.8% | 14.9% |
| 3番手の1着率 | 0.6% | 2.6% |

**まだ足りないところ**: 捲りが決まる割合が少なめ。3番手・単騎がほとんど勝たない。3番手の3着以内も少ない。

---

## 5. 入力の考え方

- どの入口(手入力・スクショ・URL)から来ても、最後は `race-data.js` の **レースデータ** にそろえる
- 一番大事な入力は **並び**。AIの推測より、出走表の並び予想や選手コメントを優先する
- 出走表の項目 → 能力値の変換ルールは仮の数字(v0)。**答え合わせ** の記録を使って直していく

---

## 6. これからの順番

1. 自分で毎レース使ってみて、答え合わせを貯める
2. 捲り・3番手・単騎のバランスを実データに近づける

4. 出走表の読み込みを楽にする (文字の貼り付け → スクショ)
5. 友達に使ってもらう
